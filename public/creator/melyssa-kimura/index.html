Creator

Melyssa Kimura

Creator and developer of Pulse of the Pacific, an independent educational tracker for the El Niño–Southern Oscillation (ENSO). The site turns public NOAA, IRI, BoM, and Copernicus climate data into a live, self-updating instrument — the current ENSO status, the full Oceanic Niño Index record back to 1950, a map of global teleconnected impacts, and a statistically grounded seasonal forecast.

This project

Pulse of the Pacific is a static, no-backend site: a scheduled pipeline fetches and validates NOAA's official indices, and the site itself is markup and vanilla JavaScript with no server-side component. Built with Python (data pipeline), HTML/CSS/JS (front end), and ECharts (visualization).
